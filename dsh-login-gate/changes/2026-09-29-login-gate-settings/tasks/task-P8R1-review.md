# P8R1-review — 记录修正 vs 证据一致性复核

## 任务
复核 P8R1-fix 的每处修正与磁盘证据一致（不臆造、不夸大）：①conversation.md 派发实录的 agent id/路径逐条抽查存在性；②tester-report.md 数字与正本一致；③completion-summary 断言逐条有据；④ERRORS.md 两条入库且语义准确；⑤确认"Phase 0-8"类措辞已清除或已改对账表。

## 产出
返回判定（通过/需修+发现清单）+ `reports/p8r1-review.md` 落盘。

## 约束
只读复核（不改文件）；发现分级（blocker/high/medium/low）；不派子代理。
